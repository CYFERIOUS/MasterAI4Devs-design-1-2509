# User Story: Integrated Skills Assessment for Recruiters

**As a** recruiter,
**I want to** automatically send skills assessments to job applicants from our Applicant Tracking System (ATS) and see the results directly in the candidate's profile,
**so that** I can quickly and objectively identify the most qualified candidates and streamline the hiring process.

## Acceptance Criteria

*   Given a job applicant has reached a specific stage in the hiring pipeline within the ATS, an assessment is automatically triggered and sent to the applicant.
*   A recruiter can manually trigger an assessment for a specific candidate directly from the ATS interface.
*   The job applicant receives a unique, secure link to complete the skills assessment.
*   Upon completion of the assessment, the results (e.g., score, summary, grade) are automatically sent back to the ATS.
*   The recruiter can view the assessment results within the corresponding candidate's profile in the ATS.
*   The system provides a clear and concise summary of the assessment results to facilitate quick decision-making.
